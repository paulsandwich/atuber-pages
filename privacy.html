Privacy Policy

Last updated: 2026-10-13

Who this applies to

This policy covers One Ear Up Publisher, a personal automation tool operated by a single individual developer for a single TikTok account that the developer personally owns. It does not accept connections from, or process data belonging to, any other TikTok account or user.

What data is accessed

The tool uses the TikTok API with the following scopes, limited to the developer's own account:

  • video.upload / video.publish — to publish AI-generated videos to the account.
  • user.info.basic — to confirm the authenticated account identity before publishing.

The tool also stores, on infrastructure the developer controls, the video files it generates and the TikTok post identifiers returned after a successful publish, solely to track publishing status and prevent duplicate posts.

What is not collected

The tool does not collect data about TikTok viewers, followers, or any third party. It does not read or process data belonging to any TikTok account other than the developer's own.

Data sharing

No data obtained through the TikTok API is sold, shared, or disclosed to any third party. Access tokens are stored only on infrastructure the developer controls and are never transmitted elsewhere.

Data retention

Access tokens are retained only as long as needed to operate the tool and can be revoked at any time by the developer through TikTok's account settings.

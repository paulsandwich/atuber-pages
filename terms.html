What this is

One Ear Up Publisher is a personal automation tool built and operated by a single individual developer. It uses the TikTok Content Posting API to publish AI-generated short videos to one TikTok account that the developer personally owns and controls.

Single-account scope

This tool is not offered as a service to the public and does not support connecting any TikTok account other than the developer's own. There is no sign-up flow, no multi-user functionality, and no third-party account access.

Content

All published content is AI-generated and is labeled as AI-generated content (is_aigc) through the TikTok API at publish time, consistent with TikTok's content disclosure requirements. Every video is reviewed by the developer before it is published.

Changes

These terms may be updated from time to time as the tool evolves. The current version always applies.
